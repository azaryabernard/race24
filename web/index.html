    HOW IT WORKS

    Exact arithmetic

    ∑

    Every hand uses all four numbers exactly once. A can be 1 or 11, while 10 / J / Q / K all count as 10.

    Division can yield fractions. Powers require integer exponents; logarithms and roots only count when the result is an exact integer.

    Difficulty considers the easiest solution and how many helpful opening moves exist. Expert hands are flagged when dealt; other ratings appear after a solution. Hands are identified by sorted values, without suits or card order.
